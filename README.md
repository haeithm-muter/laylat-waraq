# Laylat Waraq

An Arabic-first mobile quiz app built for curious players who enjoy learning, competition, and quick challenges.

Laylat Waraq brings a curated Arabic question bank into a clean mobile experience across topics such as history, geography, science, sports, entertainment, gaming, countries, and general knowledge.

## Highlights

- **4,298 curated questions** across 13 categories.
- Arabic-first interface designed for mobile use.
- Category-based quiz experience with rules and scoring.
- Account and authentication flows.
- Designed for Android and iOS.
- Structured content system that can be expanded with new categories and questions.

## Categories

The built-in question bank includes general knowledge, history, geography, science, sports, religion, countries, movies, series, anime, gaming, Spacetoon, and guessing challenges.

## Technology

- React Native
- Expo
- TypeScript
- Firebase

## Project structure

```text
app/          Application screens and navigation
components/   Reusable UI components
content/      Question categories and curated content
lib/          Application services and integrations
store/        Application state
assets/       Images, icons, and visual resources
```

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Create your local environment configuration from `.env.example`.

3. Start the application:

```bash
npx expo start
```

Never commit real credentials, Firebase secrets, signing keys, or private user data.
